# Dashboard Frontend

React 18 dashboard with Vite, Tailwind CSS, TanStack Table, and React Query.

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

Configure the API URL via `VITE_API_URL` in `.env` (defaults to `http://localhost:4000/api`).

## Available Scripts

- `npm run dev` – start the development server
- `npm run build` – production build
- `npm run preview` – preview the production build
- `npm run lint` – lint source files
